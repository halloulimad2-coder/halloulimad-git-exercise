# 🌌 InfinityHub — Premium Personal Dashboard

[![Netlify Status](https://api.netlify.com/api/v1/badges/e82b70f0-c529-4bde-8f83-c21d80b7e28a/deploy-status)](https://app.netlify.com/sites/phenomenal-blini-5e5ffa/deploys)

InfinityHub est un tableau de bord de productivité pour développeurs conçu avec une esthétique premium et des interactions dynamiques. Il a été développé et versionné pas à pas dans le cadre de la série d'exercices pratiques IFIAG.

🔗 **Lien de l'application en ligne :** [https://phenomenal-blini-5e5ffa.netlify.app](https://phenomenal-blini-5e5ffa.netlify.app)

---

## ✨ Fonctionnalités
- 🕒 **Horloge en Temps Réel** : Affiche l'heure exacte et la date en français.
- 📝 **Notes Rapides avec Sauvegarde Auto** : Un espace de notes persistantes qui s'enregistrent instantanément dans le stockage local (`localStorage`) de votre navigateur.
- 🎯 **Gestionnaire de Tâches Dynamique (To-Do List)** : Ajoutez, cochez et supprimez des tâches. Vos objectifs restent sauvegardés automatiquement.
- 💬 **Citations Inspirantes** : Une sélection de pensées célèbres de développeurs et de designers, animée toutes les 15 secondes.
- 🔮 **Design Glassmorphism Haut de Gamme** : Un arrière-plan animé avec des dégradés néon vibrants, un effet flou de fond (`backdrop-filter`) et des ombres douces et premium.

---

## 🛠️ Stack Technique
- **Structure** : HTML5 sémantique.
- **Stylisation** : CSS3 moderne, variables CSS, Flexbox, Grid, transitions cubiques et animations fluides.
- **Logique** : JavaScript ES6 natif.
- **Versionnage** : Git & GitHub.
- **Déploiement & CD** : Netlify (Continuous Deployment via Git Webhook).
